# JBG Kompetenzkompass

Browserdemo zur Kompetenzdokumentation an der Joseph Beuys Gesamtschule.

## Start

Die index.html kann direkt geöffnet oder über GitHub Pages bereitgestellt werden. Keine Installation erforderlich.

## Demonstration

1. Klasse 8a, WP Informatik und Alex Sommer auswählen.
2. In Q2 Kompetenzen bewerten.
3. In Q3 die Vorschläge aus Q1 und Q2 ansehen.
4. In Q2 unter Zeugnistext Musterbausteine zusammenstellen, bearbeiten und bestätigen.

## Grenzen

Ausschließlich fiktive Personen. Keine echten Schülerdaten eingeben. Bewertungen bleiben im lokalen Speicher des jeweiligen Browsers. Keine zentrale Speicherung, keine echte Anmeldung und keine serverseitige Zugriffskontrolle. Textbausteine sind Muster und nicht schulisch oder rechtlich freigegeben. Rollen und Koordination sind simuliert; die Zusammenführung mehrerer Lehrkräfte ist noch nicht umgesetzt.
